# Alankrita Srivastava — Portfolio 2.0

A responsive, single-page portfolio with accessible mobile navigation, scroll progress, animated section reveals, project cards, credentials, and contact links.

## Preview locally
Open `index.html` in a modern browser. The site is static and does not require a build step.

## Deploy (recommended: Netlify Drop)
1. Go to https://app.netlify.com/drop
2. Sign in to Netlify.
3. Drag the **`alankrita-portfolio-2` folder** (or upload the ZIP after extracting it) onto the page.
4. Netlify will publish a public URL. Rename the site from Site configuration if you want a cleaner URL.
5. Open the published URL on desktop and mobile to test every link.

## Deploy with GitHub Pages
1. Create a new public repository, e.g. `alankrita-portfolio`.
2. Upload `index.html` to the repository root and commit it.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the published URL shown in Pages settings.

## Add to LinkedIn
1. Open your LinkedIn profile.
2. Click the pencil/edit icon in **Contact info** and add the deployed portfolio URL under Website.
3. Set the website type to **Portfolio** if that option appears.
4. Optionally add the same URL in **Featured → Add a link** with title `My Developer Portfolio`.
5. Add the live URL to your LinkedIn About section only if it fits naturally.

## Before sharing publicly
- Verify the live demo and GitHub links for every project.
- Add verified credential URLs where available.
- If you want a custom domain, connect it in your hosting provider's domain settings.
- This is a static portfolio; project backends remain hosted separately (for example, Render/Vercel).

## Customize
Most of the text, education, certificates and project details are in the `skills`, `path`, `certs`, and `projects` arrays near the beginning of the script in `index.html`.
